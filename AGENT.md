# AGENT.md — RustCooling (Single Source of Truth)

## 1. Назначение и контекст проекта
**RustCooling** — высокопроизводительное, ультралегкое кроссплатформенное консольное приложение (CLI) и фоновый системный демон для управления встроенным LCD-дисплеем СЖО ID-COOLING серии FX на Windows и Linux.
Является официальным логическим завершением и наследником проекта `idc-lite`.
Проект учитывает все недочеты предыдущих версий на C#/WPF/Electron:
- Полный отказ от закрытых системных драйверов ядра (WinRing0).
- Исключение тяжелых фреймворков и сборщиков мусора (GC).
- Аномально низкое потребление памяти: целевое значение **до 2–3 МБ RAM**.
- Единый автономный исполняемый файл без внешних зависимостей.

Лицензия: **MIT License**.

## 2. Архитектура и стек технологий
- **Язык:** Rust (Edition 2021, версия 1.98+).
- **CLI & Парсинг аргументов:** `clap` (derive-макросы, стилизованный цветной вывод, подкоманды).
- **Связь с USB HID:** `hidapi` (open-source C-библиотека с безопасным Rust-биндингом, поддержка VID `0x3402` / PID `0x0100`).
- **Сбор системной телеметрии:**
  - Linux: чтение `/sys/class/hwmon` (температуры CPU package/core) и `/proc/stat` (загрузка ядер).
  - Windows: опрос Windows Performance Counters (PDH) и WMI через стандартные API без сторонних драйверов.
- **Анимации:** Собственный детерминированный интерполятор на `std::time::Instant` (None / Smooth EaseInOutCubic / Roller).
- **Автозагрузка:**
  - Windows: интеграция с Windows Task Scheduler (`schtasks.exe`) без прав администратора.
  - Linux: поддержка systemd user/system юнитов и udev-правил.

## 4. Спецификация аппаратного протокола (ID-COOLING FX)
- **Vendor ID (VID):** `0x3402`
- **Product ID (PID):** `0x0100`
- **Размер репорта:** 64 байта
- **Заголовок (Header):** `[0x55, 0xAA, 0x01]`
- **Команды:**
  - `CMD_TEMPERATURE = 0x01` (значение в °C)
  - `CMD_FREQUENCY = 0x02` (значение в МГц)
  - `CMD_USAGE = 0x03` (значение в процентах 0..100)
  - `CMD_SHOW = 0x04` (значение 0x01 — включен, 0x00 — выключен)
- **Контрольная сумма (Checksum):**
  - Сумма байт пакета со 2 по 61 включительно по модулю 256.
  - Позиция `frame[62]`: младший байт суммы.
  - Позиция `frame[63]`: `0xAA` (байт окончания фрейма).

## 5. Дизайн консольного интерфейса (CLI Design Tokens)
- **Цветовая палитра:** Catppuccin Mocha / минималистичный монохром с акцентами.
  - Акцент / Инфо: Циан (`#89dceb` / Cyan)
  - Нормальная температура (< 60°C): Зеленый (`#a6e3a1` / Green)
  - Предупреждение (60°C - 79°C): Желтый (`#f9e2af` / Yellow)
  - Высокая нагрузка / тревога (>= 80°C): Красный (`#f38ba8` / Red)
  - Вторичные метрики (частота, RAM, интервал): Серый (`#6c7086` / Dim)
- **Интерактивность:** однострочный `\r` индикатор состояния без мерцания терминала и спама новыми строками в режиме `run`, а также тихий фоновый запуск (`--daemon`).
